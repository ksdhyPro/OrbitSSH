# 更新日志

## v1.6.0

1. 全新升级 Windows 安装体验：采用 OrbitSSH 品牌自绘安装器，统一纯黑深色界面、应用图标、标题、按钮和许可协议控件，与软件深色皮肤保持一致。
2. 新增安装器高 DPI 适配，为 100%、150% 和 200% 缩放生成清晰的品牌图片与控件资源。
3. 修复安装进度直接跳到完成的问题，改为后台解压并按真实解压量更新进度；同时增加应用归档内容校验，避免空包被误发布。
4. 重构 Windows 发布流程，`npm run dist` 可直接生成自绘安装包及兼容 `electron-updater` 的 `latest.yml` 更新元数据。
5. 优化安装包压缩策略，在不裁剪运行文件和语言资源的前提下，将 Windows 安装包控制在 100 MB 以内。

## v1.5.1

1. 升级左侧面板布局：服务器、自定义指令和远程文件支持自由排序、独立折叠及本地记忆，最底部面板自动填充剩余空间。
2. 优化面板高度交互：打开折叠面板后自动扩展到可用最大高度，窗口缩放时按可用空间动态收紧，避免内容溢出。
3. 修复面板分隔线拖拽逻辑：中间分隔线会在相邻展开面板之间转移高度，不再错误受底部面板剩余空间限制。

## v1.5.0

1. 升级自定义指令执行体验：确认命令预览后会创建独立终端标签运行，不再占用当前正在操作的终端。
2. 支持按非空行顺序执行多条命令：终端内展示执行进度、原始命令和实时输出，上一条命令结束后再执行下一条。
3. 关闭自定义指令创建的终端标签后，立即停止后续命令发送，避免后台继续执行未确认操作。

## v1.4.0

1. 优化 Codex CLI 配置流程：本地检测失败时可手动输入 Codex CLI 可执行文件地址，并继续完成模型与思考强度配置。
2. 统一终端与 SFTP 的右键菜单视觉样式，提取通用菜单组件并支持分组、分割线及悬浮展开的多级菜单。
3. 新增服务器专属自动化任务：支持保存多行 Shell 脚本、执行前确认、独立 SSH 会话运行、实时输出展示与停止任务，不影响当前终端会话。

## v1.3.0

1. 新增 SFTP 文件夹下载：选中文件夹后可递归下载完整目录结构，下载前可选择本地目标目录，默认定位桌面并兼容 Windows、macOS。
2. 升级 AI 跨服务器协作能力：可通过已保存的 SSH 连接定位目标服务器执行诊断命令，连接凭据不暴露给模型；涉及修改、传输或 Docker 操作时会展示命令授权卡，由用户确认后执行。
3. 优化 AI Agent 执行编排，移除单轮固定 10 条命令限制，改为结合执行时长、重复命令和连续无进展次数的动态预算，复杂排查可连续完成必要步骤。
4. 修复 Docker 只读查询识别不完整的问题，容器数量统计等命令可正常执行；同时禁止 AI 借助当前终端自行 SSH、SCP 或 SFTP 到其他服务器，确保跨服务器操作始终使用已保存连接。
5. 优化终端会话标签栏：服务器较多时支持滚轮横向滚动并显示细滚动条，标签不会溢入 AI 面板；关闭按钮图标恢复居中。

## v1.1.7

1. 新增服务器置顶功能，可在服务器列表中快速置顶或取消置顶常用连接，置顶状态会持久化保存并在主进程、Preload 和界面列表中保持一致排序。
2. 加固 AI 命令安全策略，区分明确只读命令与仅“完全访问”模式放行的未知命令，并补齐绝对路径、引号包装、`env`、`command`、`nice`、`nohup`、多行和复合命令等风险识别。
3. 新增 AI 终端上下文隐私开关，最近终端输出默认不发送；用户显式开启后会先脱敏密码、Token、Authorization、URL 凭据和私钥，再按上下文预算发送给在线模型。
4. 修复 AI 终止与审批生命周期，普通请求和审批后命令均可终止，SSH 超时或取消会关闭执行 Channel；审批支持主动过期、一次性消费，并在新请求或终端关闭时自动清理。
5. 优化 AI Agent 架构，将编排、模型适配、SSE 解析、上下文构建、输入校验和审批存储拆分为独立模块，单轮命令上限调整为 10，并新增 15 项 Node 内置专项测试。
6. 强化 AI IPC 输入校验，限制消息、历史和命令长度，校验标签页上下文和审批归属，只接受 `run_shell_command` 工具调用，并兼容无空格 `data:` 的 SSE 响应。
7. 优化大型模块结构，将主题变量、终端和弹窗等 Renderer 样式拆分为独立文件，并将远程文件交互、终端命令执行和系统统计提取为专用模块，确保相关代码文件保持在 1000 行以内。
